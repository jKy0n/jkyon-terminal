# Zellij — Atalhos Essenciais

| **Ação**                              | **Atalho**                                                                  |
| :-------------------------------- | :---------------------------------------------------------------------- |
| Criar novo painel                 | `Alt n`                                                                 |
| Toggle horizontal ↔ vertical      | `Alt [` / `Alt ]` (cicla layouts `vertical` / `horizontal` / `stacked`) |
| Fechar painel focado              | `Ctrl p` → `x`                                                          |
| Alternar entre painéis            | `Alt h` / `Alt j` / `Alt k` / `Alt l` (ou setas)                        |
| Aumentar / diminuir painel        | `Alt =` / `Alt -`                                                       |
| Criar/mostrar floating pane rápido| `Alt f`                                                                 |
| Renomear painel                   | `Ctrl p` → `c`                                                          |
| Renomear aba / sessão             | Aba: `Ctrl t` → `r` · Sessão: `Ctrl o` → `w`                            |

---

Pressione `q` para fechar esta ajuda.
